# Factoriza los siguientes polinomios a su mínima expresión

### 57) 125 + 8x^3
- **Procedimiento:**
  $$125 + 8x^3$$
  $$= (5)^3 + (2x)^3$$
  $$= (5 + 2x)[(5)^2 - (5)(2x) + (2x)^2]$$
  $$= (5 + 2x)(25 - 10x + 4x^2)$$
- **Resultado:**
  $$(5 + 2x)(25 - 10x + 4x^2)$$

### 58) 64 - x^3
- **Procedimiento:**
  $$64 - x^3$$
  $$= (4)^3 - (x)^3$$
  $$= (4 - x)[(4)^2 + (4)(x) + (x)^2]$$
  $$= (4 - x)(16 + 4x + x^2)$$
- **Resultado:**
  $$(4 - x)(16 + 4x + x^2)$$
