# Factoriza los siguientes polinomios a su mínima expresión

### 33) 5n^3 + 31n^2 - 28n
- **Procedimiento:**
  $$5n^3 + 31n^2 - 28n$$
  $$= n(5n^2 + 31n - 28)$$
  $$= n(5n^2 + 35n - 4n - 28)$$
  $$= n[5n(n + 7) - 4(n + 7)]$$
  $$= n(5n - 4)(n + 7)$$
- **Resultado:**
  $$n(5n - 4)(n + 7)$$

### 34) 42n^2 + 180n + 162
- **Procedimiento:**
  $$42n^2 + 180n + 162$$
  $$= 6(7n^2 + 30n + 27)$$
  $$= 6(7n^2 + 21n + 9n + 27)$$
  $$= 6[7n(n + 3) + 9(n + 3)]$$
  $$= 6(7n + 9)(n + 3)$$
- **Resultado:**
  $$6(7n + 9)(n + 3)$$
